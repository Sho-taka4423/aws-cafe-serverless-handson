# Challenge #1 ★☆☆ メニューが表示されない！

## 症状

> 店長「アプリを開くとエラーになるんです…お客様がメニューを見られません！」

お客様アプリを開くと、メニュー欄にこんなエラーが出ます。

```
メニューを読み込めませんでした（HTTP 502 / Internal server error）
```

## ミッション

メニュー（`GET /menu`）が表示されるようにしてください。

直せたら、お客様アプリで Challenge #1 の「クリア判定」を押します。✅ が出ればクリアです。

## 調べるとよい場所

- AWS Lambda の関数 `aws-cafe-<環境ID>-order-function`
- Amazon CloudWatch Logs（店員さんの業務日報）

## 知っておくとよい言葉

HTTP 502 は、受付窓口（API Gateway）が「店員さん（Lambda）からまともな返事をもらえなかった」ときに返すエラーです。窓口ではなく、店員さんの側で何か起きています。

では店員さんに何があったのか。それはたいてい業務日報、つまりログに書いてあります。障害対応はまずログから見るのが鉄則です。

困ったときは、アプリの「店長のつぶやき」（ヒント）を見てみましょう。
