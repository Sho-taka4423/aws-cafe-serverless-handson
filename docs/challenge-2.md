# Challenge #2 ★★☆ 伝票が表示されない！

## 症状

> 店長「開店前の予約注文が厨房に届いているはずなのに、お店の画面に伝票が1枚も出てこないんです！」

お客様アプリの「🧾 厨房の注文伝票」欄に、こんなエラーが出ています。

```
伝票を読み込めませんでした（HTTP 502）
```

## ミッション

注文伝票（`GET /orders`）が表示されるようにしてください。

直せたら Challenge #2 の「クリア判定」を押します。予約の伝票が表示され、✅ が出ればクリアです。

## 調べるとよい場所

- DynamoDB のテーブル `aws-cafe-<環境ID>-orders`（「項目を探索」で中身を見られる）
- CloudWatch Logs（店員さんの業務日報）
- Lambda 関数の「設定」→「アクセス権限」と、そこから開ける IAM ロール

まずは「伝票が本当に届いているのか」を、DynamoDB で自分の目で確かめてみてください。伝票があるのに見えないのか、そもそも伝票がないのかで、疑う場所が変わります。

## 知っておくとよい言葉

IAM ロールは、Lambda が「何をしてよいか」を決める社員証のようなものです。伝票を「書く」権限と「読む」権限は別々に許可します。

権限は、必要な操作を必要な相手（リソース）にだけ許可するのが基本です。これを最小権限と呼びます。

> ⚠️ 正しく直しても、数分のあいだエラーが続くことがあります。運営の検証でも、ここで「直したのに動かない…」と一度ハマりました。困ったら「店長のつぶやき」のヒント3を見てください。
