# Challenge #4 🎉 FINAL 開店！最初のお客様の注文を通せ！

## 状況

> 店長「最初のお客様がいらっしゃいました！」
> お客様「カフェラテの M サイズをください。名前は水野です」

## ミッション

お客様アプリの「📱 ご注文」から、この注文を送ってください。

| 商品 | サイズ | お名前 |
|---|---|---|
| カフェラテ | M | 水野 |

「🧾 厨房の注文伝票」に出てくれば、注文は厨房まで届いています。Challenge #4 の「クリア判定」を押して ✅ が出たらクリア。「開店成功！🎉」の画面が出れば、お店は無事オープンです。

## うまくいかないとき

まず Challenge #1〜#3 の「クリア判定」をもう一度押して、どこがまだ壊れているかを確かめてください。どれも ✅ なのに判定が通らない場合は、「伝票を更新」を押してから判定し直します。名前やサイズの打ち間違いもよくあるので見直してみてください。

## ふりかえり

最初のお客様の注文は、こんな順で流れました。

```
お客様アプリ ─POST /orders→ API Gateway ─→ Lambda ─PutItem→ DynamoDB
お客様アプリ ←GET /orders── API Gateway ←─ Lambda ←─Scan─── DynamoDB
```

途中のどこか1か所でも壊れていれば、お客様にコーヒーは届きません。今日直した3つの障害が、この図のどこで起きていたか思い出してみてください。
